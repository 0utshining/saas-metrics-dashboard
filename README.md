# SaaS Metrics Dashboard

This project includes automated ChatGPT integration for:
- Code review on pull requests
- Documentation generation
- Issue triage and categorization

## Setup

1. Add your OpenAI API key as a GitHub Secret: `OPENAI_API_KEY`
2. Workflows will trigger automatically on PR creation, code changes, and new issues

## Workflows

- **Code Review**: Triggered on pull requests
- **Documentation**: Triggered on commits
- **Issue Triage**: Triggered on new issues
