# SaaS Metrics Dashboard Roadmap

This roadmap describes the planned development direction for the open-source
SaaS Metrics Dashboard.

The roadmap may evolve based on technical requirements, user feedback, issues,
and community contributions.

## v0.1 — Foundation

Goal: establish a usable, dependency-light SaaS metrics dashboard.

- [x] Responsive dashboard interface
- [x] MRR calculation
- [x] ARR calculation
- [x] Month-over-month revenue growth
- [x] Customer churn calculation
- [x] ARPU calculation
- [x] CAC calculation
- [x] Estimated LTV calculation
- [x] LTV:CAC ratio
- [x] Revenue visualization
- [x] Customer-growth visualization
- [x] Synthetic sample dataset
- [x] Contribution guidelines
- [x] Security policy
- [x] Open-source license
- [ ] Automated tests
- [ ] GitHub Actions validation

## v0.2 — Data Management

Goal: make the dashboard useful with user-provided datasets.

- [ ] CSV import
- [ ] JSON import
- [ ] CSV export
- [ ] Input validation and error reporting
- [ ] Historical period management
- [ ] Local browser persistence
- [ ] Improved chart controls

## v0.3 — Expanded SaaS Metrics

Goal: support a broader SaaS analytics workflow.

Planned metrics include:

- [ ] Net Revenue Retention (NRR)
- [ ] Gross Revenue Retention (GRR)
- [ ] Expansion MRR
- [ ] Contraction MRR
- [ ] New MRR
- [ ] Churned MRR
- [ ] Quick Ratio
- [ ] Revenue churn
- [ ] Customer lifetime
- [ ] Payback period

## v0.4 — Analysis and Reporting

Goal: improve decision-support capabilities.

- [ ] Period-over-period comparisons
- [ ] Metric trend indicators
- [ ] Configurable reporting periods
- [ ] Dashboard filters
- [ ] Printable reports
- [ ] Exportable dashboard summaries
- [ ] Metric explanations and methodology references

## v1.0 — Stable Release

The first stable release should provide:

- Reliable metric calculations
- Automated test coverage
- Accessible responsive interface
- Data import and export
- Historical SaaS analysis
- Clear metric methodology
- Stable documented data format
- Contributor documentation
- Security documentation

## Longer-term ideas

Potential future work includes:

- Optional integrations with SaaS billing platforms
- Privacy-conscious analytics workflows
- Additional visualization types
- Custom metric definitions
- Multi-currency support
- Internationalization
- Plugin or extension architecture

These items are exploratory and are not commitments.

## Contributing

Community feedback and contributions are welcome.

See `CONTRIBUTING.md` for contribution instructions.

If you would like to work on a roadmap item, consider opening an issue first so
the implementation can be discussed before significant development work begins.
